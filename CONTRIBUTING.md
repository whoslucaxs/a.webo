# Contributing to a.webo

Use [Issues](https://github.com/whoslucaxs/a.webo/issues) for bugs and feature requests. Include your operating system, app version, steps to reproduce, and relevant debug logs. Remove invitation links and secrets before posting logs.

For code changes, open a [pull request](https://github.com/whoslucaxs/a.webo/pulls) against `main`. Keep changes focused and run `pnpm test` and `pnpm run build`. See [README.md](README.md) for setup and [backend/README.md](backend/README.md) for server work.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md) in project discussions.
