# Contributing to a.webo

Use [Issues](https://github.com/whoslucaxs/JanjaShare/issues) for bugs and feature requests. Include your operating system, app version, steps to reproduce, and relevant debug logs. Remove invitation links and secrets before posting logs.

For code changes, open a [pull request](https://github.com/whoslucaxs/JanjaShare/pulls) against `main`. Keep changes focused and run `pnpm test` and `pnpm run build`. See [README.md](https://github.com/whoslucaxs/JanjaShare#readme) for setup and [backend/README.md](https://github.com/whoslucaxs/JanjaShare/blob/main/backend/README.md) for server work.

Follow the [Code of Conduct](https://github.com/whoslucaxs/JanjaShare/blob/main/CODE_OF_CONDUCT.md) in project discussions.
